Overview

This coding project implements Geometric Brownian Motion to model random stock market variability. The original interactive Python code in VS Code implements sliders and text inputs for the number of years, initial investment, expected return, standard deviation, and number of scenarios. This project comes completely from following along with a tutorial by Daniel Boctor that I have linked below.

Example Code

def gbm(n_years=10, n_scenarios=50, mu=0.07, std=0.15, steps_per_year=12, S_0=1000):
            dt = 1 / steps_per_year
            n_steps = int(n_years * steps_per_year)
            rets = np.random.normal(
                loc=(1 + mu) ** dt,
                scale=std * np.sqrt(dt),
                size=(n_steps, n_scenarios)
            )
            rets = pd.concat(
                [pd.DataFrame(np.ones((1, n_scenarios))), pd.DataFrame(rets)],
                ignore_index=True
            )
            return S_0 * pd.DataFrame(rets).cumprod()
